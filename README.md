# Datt Studio — Astro + Sanity Starter

## Quick start

1. Install dependencies:
   ```
   npm install
   ```

2. Run Astro dev server:
   ```
   npm run dev
   ```

3. (Optional) Run Sanity Studio if you set it up separately:
   ```
   sanity start
   ```

## Notes

- This starter uses local placeholders for Sanity. Fill `.env` with your SANITY_PROJECT_ID and SANITY_DATASET when ready.
- Deploy the Astro site to Vercel and the Sanity Studio to Sanity hosting (or wherever you prefer).
